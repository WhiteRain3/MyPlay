**On the phone**

- A new Backup page (and its tile): save all your settings to a file, or load them back from one,
  for example on a new phone. Trusted head units, certificates, custom wallpaper photos and a few
  phone-specific or safety options are left out; set those by hand. Loading a file can switch on
  options that go online (the update check, the weather, the browser), if they were on when it
  was saved.

**Behind the scenes**

- From AARE (by Jason F.): settings for the car screen's density, text size and control size.
  The phone controls for them come in a later release; they are already saved in backups.
- A density from a backup file that is far outside what a car screen can use is ignored, so a
  damaged file cannot make the car screen unreadable.

Nothing in this release has been tried in the car yet.
