**Speed limits: only real estimates are dashed, and ready for filled-in limits**

- **Limits from the kind of road or the zone are solid again:** towns, motorways and living streets
  show a normal sign, as in 0.1.60. These are the legal limits, not guesses.
- **Ready for estimated limits:** this version can read a new speed-limit file that fills in
  Lithuania's usual limit where the map has none (50 in towns, 90 outside, 70 on gravel). Those
  limits will show as a dashed sign, marked "estimate (no sign in the map)". **The new file is not
  published yet**, so for now nothing is filled in; the app keeps using the current file and will
  pick up the new one on its own once it is out.
- **Car > Speed > "Fill in standard limits"** now hides only those estimates; limits from signs,
  the kind of road and the zone always show. With it off, a signed road right next to an estimated
  one is still found.
- **Fixed:** the size shown before a speed-limit download could be the old file's after a brief
  network problem.
- **Correction to 0.1.61's notes:** the flicker fixed there was in Waze's message shown in the
  turn's place on the home, not in a banner.
- **For us:** if the release's tests pass only on a retry, the release run now says so with a
  warning, instead of hiding it.
